# 选段与文案

B-roll 的工作是：**观众耳朵在听一句话，眼睛同时“看见”这句话里的那个信息**。不是把口播再写一遍。

## 哪些段落值得做

先找“能被看见”的信号，一条至少命中一个：

| 信号 | 例子 | 模板 |
|---|---|---|
| 一个扛得住整帧的数字 | 7000 条笔记、90%、3 年 | `number` |
| 有顺序的步骤 | 先分类、再打标签、然后… | `steps` |
| 很多 → 很少 | 30 多个文件夹收敛成 6 类 | `converge` |
| 同一件事的前后两个量 | 以前 8 分钟，现在 30 秒 | `compare` |
| 关系 / 连接 / 规模感 | 1 万 2 千条双链、互相引用 | `network` |
| 整段的结论或钩子 | 问题是你的笔记之间有没有连接 | `quote` |
| 几个并列项里有一个是重点 | 三关，90% 死在第一关 | `focus` |
| 先立一个认知再推翻 | 很多人以为…其实… | `versus` |
| 章节口 | 第一个…第二个…第三个… | `title` |
| 观众需要看见原件才信 | 我的后台、原帖、关系图 | `shot` |

**拦下来，不做的**（写进“落选段 → 去处”）：

- 软件操作过程 → 录屏
- 情绪、场景、故事（“那天我坐在工位上…”）→ 实拍 / 角色动画
- 隐喻（“知识库像一座图书馆”）→ 隐喻动画；信息动画不画比喻
- 没有新信息的过渡句（“我们来看下一个”）→ 不需要画面

## 数量

- 默认挑 **5–8 条**；用户指定数量就按用户的。宁缺毋滥：一条平庸的 B-roll 比没有更糟。
- 相邻两条不用同一模板；同一模板全片 ≤ 2 次（`title` 章节卡系列除外）。
- 同一段里有两个信号时，选**观众最可能记住的那一个**，另一个放弃或拆成相邻两条。

## 提炼屏幕文字

口播是给耳朵的，屏幕字是给眼睛的。眼睛在 0.5 秒里只能抓住一个词组。

1. **从原话里摘，不改写**：可以删字、可以断行，不能换说法、不能加词。“它根本消化不了”可以留成“它根本[消化不了]”，不能写成“AI 处理不过来”。
2. **数字原样**：口播说“1 万 2 千”，屏幕可以写 `12,000`（同一个值换写法）；不能四舍五入、不能换算出台词里没说的结论（比如“效率提升 16 倍”——台词没说就不写）。
3. **字数上限**（超了就删，模板的 `fit()` 只负责微调）：
   - 标题 / 论点：每行 ≤ 8 字，≤ 2 行（`quote` ≤ 3–4 行，每行 ≤ 7 字）
   - 单位 / 标签：≤ 4 字
   - 步骤名 / 选项：≤ 5–7 字
4. **断行按意群**：`直接丢给 AI\n它根本消化不了`，不要把一个词劈在两行。
5. **重点用 `[ ]` 标出**：一帧最多一处，渲染成 B 墨荧光压条（或 B 墨字，≥ 100px 时）。
6. **台词没给的内容留空**：“收敛成 6 大类”但没说哪 6 类 → 6 个只带序号的空块（`names: []`）。不替用户编类别名、编案例、编数据。

## 时长

B-roll 盖住的是“这句话被说出来的那几秒”。

```bash
node scripts/timing.mjs --srt 口播.srt "7000 条笔记直接丢给 AI" "后来我把整个流程拆成了 4 步"
node scripts/timing.mjs "7000 条笔记直接丢给 AI，它根本消化不了"     # 没有字幕时按 4.5 字/秒估
```

把建议的 `duration` 填进 DATA。关键落点（数字砸下、压条刷出）最好落在那个词被说出来的时刻附近——有 SRT 时，在分镜表里写下入点，剪辑时对齐。

## 色本分配

四组色本（见 [style.md](style.md)），**一个功能段锁一组**，同一条视频最多用 2 组：主色本给正文，另一组给钩子 / 结论（首尾呼应）。不要每条换一个颜色。

## Gate 1 的产出格式

```markdown
| # | 原话落点 | 模板 | 屏幕文字 | 时长 | 色本 | 截图 |
|---|---|---|---|---|---|---|
| 01 | “7000 条笔记直接丢给 AI，它根本消化不了” | number | 7000 / 条笔记 / 直接丢给 AI↵它根本[消化不了] | 4.5 | blue | — |
| 02 | “流程拆成了 4 步：先分类…最后做交叉链接” | steps | 拆成 4 步 / 分类·打标签·建索引·交叉链接 | 5 | blue | — |

落选段：
- “很多人以为做知识库就是把笔记堆进去” → 并进 00 versus（误区）
- “那天我…” → 实拍
```
