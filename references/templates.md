# 模板手册

每个模板都是完整可渲染的 composition。用法：复制到项目 `compositions/NN-名字.html`，**只改顶部的 `const DATA = {…}`**。版面会按字数自动排；字太多时 QA 会报 `fit` 溢出——那是让你删字，不是让你改 CSS。

下面每个模板的示例 DATA 就是它的默认值，全部来自同一段虚构逐字稿（[examples/demo-script.md](../examples/demo-script.md)）。

所有模板共有的字段：

| 字段 | 说明 |
|---|---|
| `palette` | `pal-blue` / `pal-teal` / `pal-red` / `pal-ink` |
| `mast` | `[左, 右]`：左 =「段号 · 主题词」，右 =「序号 / 总数」。主题词写更上一层的分类，**不能和本帧正文同词**（QA 会报 error） |
| `duration` | 秒。用 `scripts/timing.mjs` 算 |

`[ ]` 标记 = 一处 B 墨重点（压条或 B 墨字）。

---

## number · 数字冲击
**用于** 一个能扛住整帧的数字。**故事** 数字网点显影 + 计数 → 套印归位 → 单位盖章压在数字脚上（叠印出第三色）→ 论点升起 → 重点压条。

```js
number: 12, prefix: '', suffix: '', comma: false,     // 8 位以内；≥ 10000 建议 comma
unit: '处信息',                                        // ≤ 4 字
say: '值得配[画面]',                                   // ≤ 2 行 × 8 字
```

## steps · 流程拆解
**用于** 2–6 个有顺序的步骤。**故事** 标题里步数是 B 墨大字 → 一行一步像排好的目录表（细线刷出、序号显影、步骤名升起，一步接一步）→ 右侧网点淡印的大步数 → 落点那一步压条。

```js
title: ['只有', 3, '步'],                 // [前半, 数字, 后半]
steps: ['选段', '出样帧', '渲成片'],         // 每步 ≤ 5 字
key: -1,                                 // 落点那一步（-1 = 最后一步）
```

## converge · 收敛归类
**用于** 很多 → 很少。**故事** 「30+ → 6」两个数字 → N 张小卡逐张落下 → 小卡分组飞进 K 个大块被吸收，大块平网印出 → 少的那个数字盖章。

```js
from: { n: '30+', cap: '套动效工程', count: 30 }, // count = 画多少张小卡（≤ 36）
to:   { n: '4',   cap: '类',       count: 4 },    // 2–6 个大块
names: ['数字', '流程', '对比', '金句'],            // 大类名：台词给了才填，没给就 []
```

## compare · 前后对比
**用于** 同一件事的两个量（时间、次数、成本）。**故事** 两根条按**真实比例**：“以前”匀速长满（数字跟着爬，像时间在走）→ “现在”一下到位、数字盖章。慢 vs 快本身就是论点。

```js
title: '做一张信息图',
before: { label: '以前', value: 40, unit: '分钟', base: 2400 },  // base = 换算成同一单位（秒）
after:  { label: '现在', value: 2,  unit: '分钟', base: 120 },
```
比例差太悬殊（> 50 倍）时短条会只剩一个点——这正是要表达的，不要“为了好看”放大。

## network · 连接 / 密度
**用于** 关系、链接、网络效应。**故事** 大数字 + 单位叠印 → 论点 → 一张网从中心向外长出（节点弹出、连线逐条画），数字和连线同步爬升。

```js
number: 1800, comma: false, unit: '条画面',
say: '放在一起[是一个系列]',   // 一行 ≤ 10 字
nodes: 58,                    // 网是示意，不代表真实数量
```

## quote · 金句 / 结论 / 钩子（满版深底）
**用于** 整条视频的论点落地。全片 ≤ 2 条。**故事** 第 0 帧就是满版墨底 + 半个网点太阳 → 引子刷出 → 大字逐字升起 → 关键词 B 墨显影 + 套印归位。

```js
lead: '所以，别再从一张白纸开始了',          // 可空；≤ 16 字
quote: '画面要跟着\n[你说的话]走',           // 2–4 行 × ≤ 7 字
```

## focus · 多选一 / 卡点
**用于** 几个并列项里有一个是重点。**故事** 纸条依次滑入 → 落选项退网成平网（还读得出，但退后了）→ 选中项刷满 B 墨、往前一步 → 结论数字盖章。

```js
title: '四组色本',
items: ['墨蓝配荧光粉', '深青配橙', '藏青配朱红', '墨黑配明黄'],   // 2–5 项 × ≤ 7 字
pick: 0,
verdict: { n: '70%', text: '的视频都用它' },   // 没数字时 n: ''；没结论时 verdict: null
```

## versus · 误区翻转
**用于** “很多人以为…其实…”。**故事** 误区那句印出来 → 一笔划掉 → 整块退网 → 中线刷开 → 真相升起 + 关键词压条 + 套印归位。

```js
before: { tag: '以为', text: '好看的动效\n得请人来做' },
after:  { tag: '其实', text: '一份逐字稿\n就[够了]' },
```

## title · 章节卡
**用于** 第一个 / 第二个… 的章节口；开场标题。同模板换 `index` 派生整套，可以 `flood: true` 与浅底交替。**故事** 巨大序号从下往上印出 → 套印归位 → 小标签刷出 → 宋体标题叠印压住序号的脚。

```js
flood: true, index: '01', kicker: '第一部分', title: '先看效果', sub: '',
```

## shot · 截图锚点
**用于** 观众需要看见原件才信的那句。**故事** 四角裁切标记弹出 → 截图从上往下刷入，A 墨双色调 + 网点显影 → （仅真截图）一处 B 墨批注框盖章 → 说明升起。

```js
img: '../assets/shots/storyboard.png',  // 空 = “待替换”占位
slot: '分镜表截图',                     // 占位时写清楚要什么截图
note: { x: .52, y: .30, w: .30, h: .22 },   // 批注框（相对版位比例）；没有真截图时必须是 null
height: 780, caption: '上周的分镜表', source: '截图 · 2026-10',
```
截图会被处理成 A 墨双色调——任何截图进来都自动“属于”这套视觉，不用调色。

## 选哪个？

```
台词里有数字吗？
├─ 一个数字           → number
├─ 两个同单位的数字    → compare
├─ 多 → 少            → converge
└─ 数字 + “连接/关系”  → network
有顺序的几步？         → steps
几项里挑一个？         → focus
先错后对？             → versus
整段的结论 / 钩子？    → quote
章节口？               → title
要看原件？             → shot
```
