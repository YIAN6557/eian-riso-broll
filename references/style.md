# 视觉系统 · 孔版双色

所有部件都在 `assets/riso.css`。这份文档解释每条规则为什么存在，改样式前先读。

## 为什么是 Riso

竖屏信息动画在手机上被看 1–3 秒。它需要：**一眼可读的明暗反差**、**一个明确的重点**、**和口播画面明显不同的质感**。孔版印刷天然满足：两种油墨 = 强制克制；荧光色 = 天然的重点；网点和错位 = 一眼就知道“这是印出来的”，而不是又一个 PPT 动画。

## 五个部件

1. **纸**：纯色纸场 `--paper` + 纤维噪点 `.fiber`（正片叠底）+ 油墨不匀 `.press`（滤色，逐两帧换位 = 颗粒在呼吸）。纸面上**没有任何渐变**——“渐变”一律用网点画。
2. **A 墨（深）**：所有小字、结构线、框线。正片叠底，压在 B 墨上会变成更深的第三色。
3. **B 墨（荧光）**：大数字、压条、色块、网点地层、一处印章。正片叠底 + 全版统一错位 `translate: var(--rx) var(--ry)`（默认 3px, -2px）——**错位必须是整版一致的**，因为真实印刷里是整张 B 版没对准，不是每个元素各歪各的。
4. **网点**：
   - `.print` 显影：一层墨从小点长成实地（入场）。
   - `.tint` 平网：墨只印 25–45%（退后、背景大字、落选项）。
   - `Riso.halftone()` 画布：点径随位置变化的网点（地层、太阳）。网线角 45°。
5. **满版墨底 `flood`**：整张纸印满 A 墨，字变成纸色反白。全片 ≤ 2 帧，用在钩子 / 结论——它的作用是**节奏**，用多了就没有节奏。

## 色本

| class | 纸 | A 墨 | B 墨 | 气质 |
|---|---|---|---|---|
| `pal-blue`（默认） | `#F3EEE4` | 墨蓝 `#22308C` | 荧光粉 `#FF4C97` | 最“Riso”，适合知识、科技 |
| `pal-teal` | `#F1EDE3` | 深青 `#0C4A4C` | 橙 `#FF6A2A` | 温暖、方法论、生活 |
| `pal-red` | `#F2ECE2` | 藏青 `#1C2A4E` | 朱红 `#F0433A` | 观点、误区、警告 |
| `pal-ink` | `#EEEAE1` | 墨黑 `#1B1B1B` | 明黄 `#FFC21A` | 严肃、数据、财经 |

- 一个功能段锁一组；一条视频最多 2 组。
- 新色本：A 墨对纸的对比度必须 ≥ 7；B 墨只用在大元素上，100–200px 的字 ≥ 2.0、200px 以上 ≥ 1.3 即可（`pal-ink` 的黄 ≈ 1.4，只适合超大数字和色块）。叠印色（A×B）要比 A 更深，不能发灰。
- `pal-ink` 的 B（黄）与 A（黑）叠印后是黑——没有第三色，所以它最克制。

## 版面

```
y 0–168     平台顶栏（搜索框 / 状态栏）：不放任何东西
y 176–234   版头 .mast：左「段号 · 主题词」+ 右「序号」+ 下划线 —— 全系列签名
y 260–1330  信息区：所有文字只能在这里
x > 930, y 880–1500   右侧按钮栏（点赞 / 评论 / 分享）：避免放字（QA 警告）
y 1330–1920 字幕床：只放网点地层 / 太阳等装饰，绝不放字
左右边距 72px
```

- 每帧 **3–5 个元素组**。挤了就删信息，不缩字号。
- 一帧 **一个主角**，占信息区的 40% 以上：超大数字、一张表、一张网、一个序号。没有主角的帧就是 PPT。
- 一帧只有 **一处 B 墨重点**（压条 / 印章 / 色块三选一），大数字和地层不算。

## 字

| 用途 | 字体 | class | 规则 |
|---|---|---|---|
| 标题、论点 | 宋体 Black（Songti SC 900） | `.hd` `.hd-xl/l/m/s` | 字距 -0.02em；不描边、不阴影 |
| 数字 | DIN Condensed Bold | `.num` | 越大越好；按墨迹对齐（`Riso.inkBox`） |
| 标签、引子 | 苹方 Semibold | `.lb` | 42px 左右 |
| 编号、版头 | Menlo | `.mono` | 28px、字距 0.16em；只放编号 / 段号，不放句子 |

- 最小字号 28px（1080 宽的画面在手机上约缩到 36%）。
- 宋体 Black 的横细竖粗在大字号下非常漂亮，小于 64px 时改用苹方。

## 禁止

渐变背景、玻璃拟态、投影（Riso 没有影子——层次靠叠印和网点）、圆角卡片、通用图标（火箭 / 灯泡 / 对勾 / 齿轮）、emoji、3D、粒子、假界面截图、第三种油墨颜色。
